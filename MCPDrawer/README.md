# PixelForge

Редактор pixel art спрайтов и анимаций в браузере + MCP-сервер, через который Claude рисует в том же редакторе в реальном времени.
Без зависимостей: только Node.js ≥ 18 (`npm install` не нужен).

## Запуск

```bash
npm start            # редактор на http://localhost:7420
npm test             # end-to-end тест MCP-сервера
```

MCP-сервер (`src/mcp.js`) сам поднимает веб-сервер в фоне, если тот не запущен, поэтому редактор доступен по
http://localhost:7420 всегда, когда Claude работает с инструментами PixelForge.

Подключение к Claude Code (уже сделано в `~/.claude.json`, user scope):

```json
"mcpServers": {
  "pixelforge": { "type": "stdio", "command": "node", "args": ["C:/Users/Nergal/Desktop/MCPDrawer/src/mcp.js"] }
}
```

Переменные окружения: `PIXELFORGE_PORT` (по умолчанию 7420), `PIXELFORGE_DATA` (по умолчанию `data/sprites`).

## Редактор

- Инструменты: карандаш `B`, ластик `E`, заливка `G` (Shift — все пиксели цвета), пипетка `I` / Alt+клик,
  линия `L`, прямоугольник `U`, эллипс `O` (Shift — пропорции), сдвиг `V`, дизеринг `D` (Shift — другая чётность),
  шейдинг `H` (ЛКМ/ПКМ — следующий/предыдущий цвет палитры). ЛКМ — основной цвет, ПКМ — дополнительный.
- Выделение: прямоугольник `S`, лассо `Q` (Shift — добавить). `V` двигает выделенное, `Ctrl+C/X/V`, `Delete`,
  `Shift+H`/`Shift+V` — отразить, `Ctrl+A`, `Esc`/`Ctrl+D` — снять, `Enter` — опустить плавающее выделение. Рисование ограничено выделением.
- Pixel-perfect карандаш `P` (убирает «уголки»), тайлинг `T` (превью 3×3 и рисование с переносом через край),
  референс-картинка (панель справа: прозрачность, под/поверх спрайта, хранится в браузере).
- Кисть `[` `]`, зеркальное рисование `M`, onion skin `K`, сетка `#`, обмен цветов `X`.
- Масштаб: колесо мыши, `+`/`-`, `0` — вписать. Панорама: Space+перетаскивание или средняя кнопка.
- Кадры `←`/`→`, слои `↑`/`↓`, дублировать кадр `Alt+N`, проигрывание `Enter`, отмена `Ctrl+Z`/`Ctrl+Y`.
- Таймлайн: слои × кадры, двойной клик — длительность кадра, имя/непрозрачность слоя, редактирование тега.
- Палитры: PICO-8, DawnBringer 16, Game Boy, NES-like, оттенки серого, «из спрайта», рампы с hue-shift из основного цвета.
- Импорт PNG (кнопка или drag & drop, с нарезкой спрайт-листа), экспорт PNG / спрайт-лист + JSON / APNG / GIF.
- История версий 🕘: автосохранение не чаще раза в 2 минуты, хранится 20 версий (`data/backups`); удалённые спрайты — в `data/trash`.
- «Следить за Claude»: редактор сам переключается на спрайт и кадр, который сейчас рисует Claude.
- История отмены общая: Ctrl+Z в браузере отменяет и действия Claude.

## MCP-инструменты

| Группа | Инструменты |
| --- | --- |
| Спрайты | `list_sprites`, `create_sprite`, `get_sprite`, `duplicate_sprite`, `delete_sprite`, `resize` |
| Рисование | `draw_ascii`, `draw_pixels`, `draw_line`, `draw_rect`, `draw_ellipse`, `fill`, `clear`, `outline`, `replace_color`, `transform`, `copy_cel`, `draw_image`, `batch` (много операций за вызов, один шаг отмены) |
| Анимация | `manage_frames`, `manage_layers`, `set_tags`, `set_palette`, `generate_ramp` |
| Просмотр | `preview` (кадр, все кадры, onion skin), `read_pixels` (ASCII-сетка) |
| Файлы | `export_unity` (лист + .meta с нарезкой и pixel-art настройками + .anim на каждый тег), `export` (sheet+json / png / frames / apng / gif), `import_png`, `backups` |
| Редактор | `get_editor_state` (в т.ч. выделение пользователя), `open_editor`, `undo`, `redo` |

Координаты: x вправо, y вниз, (0,0) — левый верхний угол; кадры и слои с 0; слой 0 — нижний.
Цвета: hex, `"transparent"` или индекс палитры (`3` / `"p3"`).

## Безопасность

Сервер слушает только 127.0.0.1, проверяет заголовок Host (защита от DNS rebinding), принимает изменения только
с собственного origin и с `Content-Type: application/json`. Чтение и запись файлов на диске (экспорт, импорт по пути,
`draw_image`) доступны только MCP-процессу по токену из `data/token`. MCP сам перезапускает сервер, если тот
запущен со старой версией кода, а открытый редактор после этого перезагружается.

## Структура

```
src/server.js   HTTP API, статика, live-обновления (SSE)
src/mcp.js      MCP stdio-сервер → HTTP API
src/store.js    модель спрайта, операции, undo/redo, сохранение в data/sprites/*.json
src/render.js   рендер кадров, спрайт-листов, ASCII
src/png.js      PNG/APNG кодер и PNG декодер
src/gif.js      GIF-кодер
src/unity.js    экспорт в Unity (.meta, .anim)
src/config.js   порт, пути, токен, хэш сборки
public/         веб-редактор (app.js; shared/ — общие с сервером примитивы и цветовые рампы)
test/smoke.js   e2e тест через MCP
```
